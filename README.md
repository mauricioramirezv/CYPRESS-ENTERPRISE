# Cypress Enterprise Demo

Proyecto académico para enseñar:

- Component Testing
- API Testing
- Accessibility Testing
- Security Testing
- Regression Testing
- UI Coverage
- Cypress Studio
- Cypress AI

# Instalación

```bash
npm install
```

# Ejecutar aplicación en una terminal

```bash
npm run dev
```

# Abrir Cypress en otra terminal

```bash
npm run cy:open
npm run cy:run
```

# Ejecutar pruebas

```bash
npm run cy:run
```

# Tecnologías

- Cypress
- React
- Vite
- Cypress Axe
- Mochawesome

# Tipos de pruebas

## Component Testing

Pruebas aisladas de componentes React.

## API Testing

Validación de endpoints REST.

## Accessibility Testing

Validación WCAG usando axe-core.

## Security Testing

Validación básica de seguridad y autenticación.

## Regression Testing

Automatización de flujos críticos.

## UI Coverage

Cobertura funcional de la interfaz.

## Cypress Studio

Grabación automática de pruebas.

## Cypress AI

Generación automática de pruebas con IA.
